An interactive strategy dashboard for a proposed sovereign-cosmic ecosystem. It arranges ten entity concepts into two connected pillars: four globally focused purpose entities and six Minjerribah-anchored entities.

## Public page

[Explore the live dashboard](https://auraofintelligence.github.io/10_entities/).

## What is here

The single-page dashboard includes:

- expandable profiles for the ten proposed entities;
- a twin-pillar relationship view;
- stakeholder groupings for government, community, cultural, private and academic conversations;
- a staged funding roadmap, risk prompts and an implementation timeline; and
- planning buttons intended to draft profiles, pitches, emails and risk notes with Gemini.

The ordinary dashboard works in the browser. The Gemini calls currently contain no API key, so the AI drafting buttons are not a working public service.

## Open it locally

Open `index.html` in a browser. An internet connection is needed for the externally hosted Tailwind CSS, Chart.js and font files.

## Status and boundaries

This is an exploratory planning model, not a register of incorporated organisations or confirmed agreements. Entity structures, funding paths and stakeholder roles are proposals to test with the relevant legal, financial, government, community and cultural authorities.

In particular, inclusion of QYAC, MMEIC or any other organisation does not imply assent, partnership, endorsement or cultural authority for a project. Those relationships require direct, respectful engagement and confirmation.
